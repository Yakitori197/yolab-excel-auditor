# 截圖 · Screenshots

此資料夾放置 README 使用的 UI 截圖。

## 如何擷取 · How to capture

1. 啟動應用：`npm run dev`，於瀏覽器開啟 http://localhost:5173/。
2. 上傳 `samples/` 內的示範檔（例如 `messy-inventory.xlsx`）。
   - 這些檔案皆為**完全虛構的合成資料**，因此截圖天生就是去識別化的，不含任何真實資料。
3. 擷取以下畫面並存檔：
   - `home.png` — 首頁（產品介紹、隱私橫幅、上傳區）。
   - `report.png` — 健康評分與問題明細。
4. 圖片建議寬度 1280–1600px，PNG 格式。

> ⚠️ 請務必只使用 `samples/` 的合成資料或您自行建立的虛構資料擷取截圖；請勿放入任何真實或敏感資料。

## 目前狀態 · Status

`home.png`、`report.png` 為待補的預留位置。首頁的視覺風格可先參考 `public/og-image.png`。
